# ROMs Directory

Place your legally-owned `.nes` ROM files in this folder:

```text
roms/
  contra.nes
  mario3.nes
```

Then run `python main.py` (or double-click `play.bat` on Windows) to launch the **Game Library**.

> Note: `.nes` files, battery saves (`saves/`), and save states (`*.state`) are automatically ignored by `.gitignore` so personal game files are never committed to GitHub.
