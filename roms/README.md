# ROMs Directory

RetroPlay ships with **2 free, open-source NES homebrew games** so you can play immediately after downloading:

- **`2048 (Homebrew).nes`** — Classic 2048 puzzle for NES ([mmuszkow/2048-nes](https://github.com/mmuszkow/2048-nes), Unlicense / Public Domain)
- **`Snake (Homebrew).nes`** — Classic arcade Snake for NES ([cyborgx37/nesnake](https://github.com/cyborgx37/nesnake), MIT License)

### Add More Games
Copy any of your own legally-owned `.nes` ROM files into this `roms/` folder and launch `play.bat` (or `RetroPlay.exe`) — they will appear automatically in the **Game Library**.

> Note: All other `.nes` files, battery saves (`saves/`), and save states (`*.state`) are ignored by `.gitignore` so personal game files are never committed to GitHub.
